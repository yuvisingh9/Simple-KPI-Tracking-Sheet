# Simple KPI Tracking Sheet

## Project Overview
An Excel-based KPI tracking dashboard designed to summarize retail sales performance using sample order data.

## Key Performance Indicators
- Total Revenue
- Total Units Sold
- Average Order Value
- Top Product by Revenue

## Tools Used
- Microsoft Excel
- Excel formulas and structured tables

## Features
- Automatic KPI calculations
- Sample dataset containing 100 transactions
- Product revenue analysis
- Professional dashboard formatting
- Instructions for updating the data

## How to Use
1. Download `Simple_KPI_Tracking_Sheet.xlsx`.
2. Open it in Microsoft Excel.
3. View the **KPI Summary** worksheet.
4. Add or edit transactions in **Raw Order Data**.
5. Review the updated KPIs.

## Dataset Note
The dataset contains simulated sample transactions created for learning and demonstration purposes. It does not represent actual company sales.
